# 📄 PROJECT-STRUCTURE.md

## 📜 Структура проекта

```plaintext
/project-root
│-- src/
│   ├── app/                # Главные страницы и маршруты
│   ├── entities/           # Сущности
│       ├── (entity)/           # Сущность
│           ├── api/               # Запросы на сервер
│           ├── model/             # Типизация запросов
│               ├── contracts/          # Типизация параметров и ответов запросов
│               ├── types/              # Типизация сущностей
│   ├── features/           # Логика и модули, отвечающие за конкретные функции
│       ├── (feature)/          # Фича
│           ├── ui/                # UI-компоненты
│           ├── api/               # Запросы на сервер
│           ├── model/             # Типизация запросов
│               ├── contracts/          # Типизация параметров и ответов запросов
│               ├── types/              # Типизация сущностей
│               ├── slices/             # Redux слайсы
│               ├── selectors/          # Функции-селекторы переменных слайса
│   ├── pagesTemplates/     # Компоненты страниц
│   ├── widgets/            # Крупные, переиспользуемые UI блоки
│   ├── shared/             # Общие утилиты и функции
│       ├── hooks/              # Кастомные хуки
│       ├── lib/                # Вспомогательные функции
│       ├── styles/             # Общие стили (SCSS)
│       ├── ui/                 # UI-компоненты
│-- public/                 # Статические файлы
│-- .gitlab-ci.yml          # CI/CD конфигурация
│-- package.json            # Список зависимостей и скриптов проекта
│-- .env                    # Файл с переменными окружения
│-- README.md               # Краткая инструкция по проекту
│-- PROJECT_STRUCTURE.md    # Этот файл - рекомендуемая структура проекта
│-- CONTRIBUTING.md         # Правила участия в разработке
```
